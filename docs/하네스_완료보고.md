# 완료 보고 — 하네스 (마크다운 지침 · 역할 · 자료, 2026-11-12)

사용자 요청: "Claude 쓰듯이 마크다운으로 지정 — 폴더별 역할에 따른 리스트 형식으로 관리. 해당 회사에 판매된 기기의 사용설명서 ·
에러 대처 같은 QA 정보를 넣으려 한다." 같은 세션(개발 역할)이 이어서 구현했다.

## 확인
- 화면(임시 서버): 관리자로 공통 지침 · A사(대상 A사)/X100 자료 · B사(대상 B사) 자료를 만들고 하네스 탭에서 목록 · 편집 확인.
  A사 사용자로 외부(가짜) 모델 실행 → 모델이 받은 시스템 지침에 공통 지침 · A사 자료 목록이 있고 B사 자료는 없음, 도구에 search_knowledge · read_knowledge.
- pytest 전체 624 통과 · 1 건너뜀 (하네스 13개 포함). 웹 tsc · 빌드 통과. 시험 뒤 진짜 계정 DB · 기록 DB · harness/ 변화 없음 확인.

## 테스트 격리 사고와 조치
- 하네스 API 테스트가 서버 모듈을 함수 안에서 불러, 공용 테스트 설정이 계정 DB 를 바꿔 끼우기 전에 돌았다 → **진짜 `data/accounts.db` 에
  시험 계정 2개(boss · h_user)가 생겼다** (로그인 사용은 꺼져 있어 영향 없음). 바로 지웠고(사용자 0개 확인), `tests/conftest.py` 가 이제
  모든 테스트에서 계정 DB · 실행 기록 DB · 하네스 폴더를 늘 임시 것으로 바꿔 끼운다.
- 참고: 진짜 `data/agent.db` 는 실행 기록이 0건이다. 파일 크기(4.5MB)와 빈 페이지 1,103개로 보아 예전에 있던 기록이 지워진 상태인데,
  `data/runs/` 의 실행 폴더(11-07 까지 50개)는 남아 있다. 이번 변경에는 기록을 지우는 코드 경로가 없고 기존 삭제 테스트는 모두 임시 DB 를 쓴다 —
  언제 비었는지는 확인하지 못했다.

## 후속 (같은 날 사용자 요청)
- 서비스 이름 'Local Agent' → **'AI Agent'** (관리 › 접속 설정에서 바꿀 수 있음 · `access.yaml` app_name · 로그인 화면 · 사이드바 · 탭 제목 · index.html).
- **추론 강도를 로컬 모델에서도** 작업마다 고른다: 낮음 = 생각 끄기, 높음 = 생각 켜기 (`Settings.think`, `providers.local_think`).
- **로그인 창이 먼저 떠야 한다** (사용자 지적): 기본을 **로그인 먼저**로 바꿨다 (`Access.login_enabled=True`). 관리자가 없으면 '첫 관리자 만들기' —
  서버 PC 에서만 (다른 PC 의 setup 은 403). 혼자 쓰기는 관리자가 일부러 끌 때만. 실제 `config/access.yaml` 도 login_enabled: true 로 바꿨다.
- 하네스 탭을 '관리'에서 **'설정 · 프롬프트'** 로 옮겼다 (예전 주소 /admin/harness 는 /settings/harness 로 넘김).
- pytest 632 통과 · 1 건너뜀, 관리 서버 재시작 후 실제 화면 확인: 들어가면 '첫 관리자 만들기', 로그인 없이 API 401 (보기만, 계정은 만들지 않음).
