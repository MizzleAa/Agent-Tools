## 2. '계정 로그인'(구독 계정)을 막은 이유 (2026-11 확인)
- Anthropic: 2026-02 약관 — Free/Pro/Max OAuth 토큰은 Claude Code·claude.ai 전용, 다른 프로그램에서 쓰면 위반 (4월부터 서버에서 차단).
- Google: Gemini CLI 약관 — 그 로그인을 다른 도구에서 쓰면 위반, 계정 정지 사례 다수.
- OpenAI: 'Sign in with ChatGPT' 요금제 사용은 오픈소스 앱과 승인받은 비공개 앱만. 상용·원격 서버 앱은 신청서(interest form) 승인 필요,
  로그인 콜백도 `127.0.0.1` 루프백 전용 → 고객사가 원격으로 접속하는 이 구조에는 그대로 맞지 않는다.
- **Claude Console(API 조직) 계정 로그인은 된다** (사용자 추가 요청 "관리자가 회사에서 받은 Claude 계정으로 로그인"): Anthropic 공식
  `ant auth login --profile <이름>`(OAuth, 조직·워크스페이스에 묶인 토큰)을 서버 PC 에서 한 번 하면, `anthropic` SDK 의 `profile=` 로
  그 계정으로 부른다 (토큰 갱신·저장은 SDK). 구현은 `Provider.auth=account_login` + `Provider.profile`.
- 이 세션에서는 내려받은 `ant.exe` 를 실행하지 못했다 (Claude Code 권한 시스템이 외부에서 받은 실행 파일 실행을 막음) → 실제 로그인은
  사용자가 서버 PC 에서 처음 한 번 실행해 확인해야 한다. SDK 쪽(프로필로 클라이언트 만들기·모델 목록·실행)은 가짜 SDK 로 시험했다.

## 후속 (같은 날 사용자 지적)
- "왜 복사해서 콘솔로 하게 유도했나" → Claude 계정 로그인을 **화면에서**: '추가하고 로그인' / 'Claude 계정으로 로그인' 버튼을 누르면 서버가
  공식 로그인 도구를 띄운다 (`agent/claude_login.py`, `POST/GET/DELETE /admin/providers/{id}/login`, `POST …/login/code`).
  서버 PC 에서 누르면 그 PC 에 브라우저 · 다른 PC 면 로그인 주소 + 코드 붙여넣기. 끝나면 모델 목록을 저절로 받음. 명령 복사 안내는 없앴다.
  (실제 `ant.exe` 는 이 세션에서 실행하지 않았다 — 가짜 로그인 도구로 두 방식 · 틀린 코드 · API 를 시험했다.)
- "새 작업에서 로컬·외부 둘 다" → 입력창 모델 선택에 외부 모델 묶음이 늘 보인다 (연결 전이면 '관리자가 연결해야 함', 관리자에게 '외부 모델 연결하기…').
