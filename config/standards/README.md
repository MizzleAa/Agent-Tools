# 개발 규격 (에이전트가 따를 규격 = QA 판정 기준)

같은 문서를 두 곳에서 쓴다.
- **로컬 에이전트**는 고른 언어의 규격대로 프로젝트를 만들고 보고한다.
- **QA**는 같은 규격과 같은 검증 등급으로 판정한다.

규격을 언어마다 나누는 이유가 있다. "프로젝트 구성, 의존성 선언, 빌드·테스트 명령, 무엇을 검증으로 인정하는가"가 언어마다 다르기 때문이다.
예를 들어 Python에서는 전역 `pip install`이 환경 오염이지만, .NET에서는 NuGet이 원래 프로젝트 로컬이다.
.NET에서 `bin/`·`obj/`는 정상 산출물이지만, Python의 `__pycache__`는 정리 대상이다.

| 문서 | 대상 |
|---|---|
| `00_공통.md` | 모든 언어: 작업 순서, 검증 등급, 완료 정의, 개발 보고 형식 |
| `python.md` | Python 3.12 (CLI, GUI, 스크립트) |
| `dotnet.md` | C# / .NET (콘솔, WPF, WinForms) |
| `node-web.md` | JavaScript/TypeScript: Node.js, 브라우저 웹 앱 |
